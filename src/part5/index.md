# Data Structures and Algorithms

## Learning objectives
- You understand what a collection is and why collections are used in programming.
- You understand the basic structure of Java's *Collections Framework*.
- You are familiar with the most common data structures in Java and their key methods.
- You understand how a dynamic list is implemented internally.
- You can implement your own simple collection data structure.
- You understand why an object's `equals` and `hashCode` methods are particularly important.
- You can evaluate how different data structures affect performance in different situations.
- You understand how recursion works.
