# Basic Principles of Java Programming language

## Learning objectives

- Get familiar with the syntax, variables and control-structures 
- Lean how Java differs from Python
- Learn to write simple Java programs and understand how code is compiled and executed

## Exercises

Each part of the material ends with a set of exercises that you submit in TIM. To pass the course, you must earn at least **50%** of the core exercise points in every part. Bonus exercises (marked with <i class="bi bi-stars jyu-gold"></i>) are optional, but their points count towards your total. The grade itself comes from the Friday oral exams, which are always about your own exercise code. See [Completing the Course](../completing-the-course.md) for the full grading criteria.
