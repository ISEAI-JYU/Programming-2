# Useful Techniques in Java

## Learning objectives

- Use lambda expressions and method references to write more concise code.
- Process collections declaratively using the Stream API.
- Handle errors using exceptions.
- Use the Maven project management tool and external libraries.
- Read from and write to files.

So far, we have learned the fundamentals of Java syntax, object-oriented programming, and the most common data structures. In this section, we will explore modern Java features and become familiar with the basic tools used for project management.

We begin by introducing Java's functional programming features and the **Stream API**, which provides an efficient way to process data without explicit loop constructs.

To improve software reliability, we will learn how to handle errors using **exception handling**. We will also see how **Maven** helps us manage external libraries and how to read from and write to files programmatically.
