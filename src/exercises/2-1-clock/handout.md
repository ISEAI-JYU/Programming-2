Create a class called `Clock` with the integer attributes `minutes` and `hours`.

Add the methods `setMinutes` and `setHours` to the class. These methods take the minutes and hours to be set as parameters.
The value of minutes must be between 0 and 59; otherwise, an error message should be printed and the time should remain unchanged. Similarly, the value of hours must be between 0 and 23; otherwise, an error message should be printed.

Also create a method called `displayTime` that prints the time in the format "HH:MM".

You can test the functionality of the class using the provided main program.
