1. Create an IDEA project. You may use the JavaFX template provided for the course.
2. Initialize a local Git repository.
3. Add `README.md` and (if necessary) `.gitignore` files.
4. Create the first commit.
5. Create a public remote repository for your project on GitLab or GitHub.
6. Push the local repository to the remote repository.

At this stage, `README.md` may contain only the project name and a brief 1–2 sentence description of the project topic.

Submit a link to your public Git remote repository for this exercise.
The easiest way to find the repository URL is from the project's page in the hosting service:

- GitLab (JYU): <https://gitlab.jyu.fi/dashboard/projects/personal>
- GitHub: <https://github.com/repos>
