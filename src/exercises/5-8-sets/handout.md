You are given two lists of numbers that contain duplicates.

Create the following sets from these numbers:

- **Union**: Contains all numbers that belong to the first set, the second set, or both.

- **Intersection**: Contains only the numbers that are present in both sets at the same time.

- **Difference**: Contains the numbers that belong to the first set but do not belong to the second set.

- **Symmetric Difference**: Contains the numbers that belong to exactly one of the sets, but not both.

The sets must not contain duplicates.

The sets can be created using the methods defined by the [Set api](https://docs.oracle.com/javase/8/docs/api/java/util/Set.html), so there is no need to iterate through the data structures with loops.

The provided main program contains examples of what these sets should contain.
