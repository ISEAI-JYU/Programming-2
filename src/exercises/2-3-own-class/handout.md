
Choose a real-world object or concept and create your own simple class for it.

Add the following to the class:

- At least two attributes that are appropriate for the class.
- At least two methods that modify or examine the state of the object in some way.
- At least two different constructors that initialize the object to a sensible state.

What constitutes a sensible state depends on the object you choose.
You may use the examples from the course material as inspiration when coming up with attributes and methods.

Create an object and experiment with changing its state in the main program. Print the object's information both before and after modifying its state.
