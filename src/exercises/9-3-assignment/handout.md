Plan your user interface views and their functionality.

Create a preliminary layout for each user interface view. You may use a diagramming tool, a drawing application, or SceneBuilder. You may also draw the layouts on paper and scan them.

Create a folder named `plan` in your project and place the images of the views there.
Also add a Markdown file named `user-interface.md` to the folder and describe the following for each view:

- What the user sees in the view (main view, edit view, etc.).
- What the user can do in the view.
- Which components are intended to implement the most important functions.

Create a new commit that includes the `plan` folder and push the changes to the Git remote repository.

Submit a link to the `plan` folder in the remote repository. You can obtain the link by opening the repository in a web browser, opening the `plan` folder, and copying the URL from the browser's address bar.
