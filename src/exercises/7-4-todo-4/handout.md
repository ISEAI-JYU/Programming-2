Aina kun käyttäjä lisää tehtävän tai muuttaa tehtävän tilaa, tallenna tehtävät
JSON-tiedostoon. Lue tehtävät ohjelman käynnistyessä. JSON-tiedoston pitäisi
näyttää esimerkiksi tältä:

```json
[
  {
    "tehtava": "Osta maitoa",
    "tehty": false
  },
  {
    "tehtava": "Vie roskat",
    "tehty": true
  }
]
```
