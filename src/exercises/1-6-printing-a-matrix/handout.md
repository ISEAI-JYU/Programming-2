Create a method called `printMatrix` that prints all the numbers in the integer matrix given as a parameter on a single line.
The method does not return anything.

Example of how the method works:

```java,ignore
int[][] matrix = {
    {42, 2, 3},
    {4, 67, 6},
    {7, 8, 9}
};

printMatrix(matrix);
```

The output should then be:

```
42 2 3 4 67 6 7 8 9
```
