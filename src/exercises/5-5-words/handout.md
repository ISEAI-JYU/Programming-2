Create a function `countWords` that takes a string as a parameter and performs the following tasks:

- Prints all _unique_ words and the number of times each word appears in the string.
- Prints the most common word separately, along with the number of times it appears in the string.
- Prints the number of unique words.

You can test your program using the provided main program, which also includes sample output.


<details><summary>Hint</summary>

You can remove punctuation from the string using its `replaceAll` method.
