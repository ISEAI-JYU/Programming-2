Your pair receives another pair's project repository. Together with your partner:

1. Clone the repository and get the application running.
2. Add **one small feature** to it. The teacher assigns the feature or approves your suggestion; it should be on the scale of a new field, a new filter, or a small new view — something a fresh pair can finish in one session.
3. Commit your work on a separate branch and push it to the repository.

Then write about half a page (as a pair, submitted in TIM) covering:

- What feature did you add, and where in the code did you build it?
- How easy was the code to understand and build in? What helped: for example the README, the naming, the structure, the commit history?
- What got in the way, and what would you suggest the other pair improve?

Be honest and concrete: the write-up is part of the evidence for the other pair's project grade, and the one you receive is part of yours. It answers the question "could another pair build in this code?"
