Create a program that prints the number of words contained in a string entered through the console.
You may assume that words are separated by a single space. Other punctuation marks do not need to be considered.

The program must print "No words" if the input is an empty string.

The program may terminate after displaying the output. It does not need to keep asking for input continuously.

Test your program by reading a string from the user and printing the number of words, for example:

```
Number of words: 5
```
