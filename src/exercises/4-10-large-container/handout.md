Create a class `LargeContainer` that acts as a container for multiple objects of any type. Objects are packed into the container so that the most recently added object is always the first one to be removed.

Add a list as an attribute to store the objects.

Also add the following methods:

- `add` adds the object given as a parameter to the end of the list.

- `take` returns the most recently added object and removes it from the list.

- `peek` returns the most recently added object without removing it from the list.

- `contains` takes an object as a parameter and returns `true` if the object is found in the container. Otherwise, it returns `false`.

- `print` prints the contents of the container. You may decide the output format yourself.

A main program is provided for testing the functionality of the class.
