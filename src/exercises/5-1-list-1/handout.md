Create a class `List`. Define an array inside it for storing the elements of the list, as well as an integer variable that keeps track of the current number of elements in the list.
Implement the method:

- `add(T element)`: adds an element to the end of the list.

At this stage, you do not need to increase the size of the data structure, so the array may become full.
Use the debugger to verify that the element has been added correctly.
Do not implement `get` or `toString` methods yet; inspect the state of the list specifically through the debugger.
