Make each view as complete as possible in SceneBuilder.

If a view contains components that will be added dynamically (for example, the tasks in the Todo application), those components should not be added in SceneBuilder. However, you should reserve space for them and assign an `fx:id` so that they can be easily referenced in code.

Add an `fx:id` to every interactive component.

Add an event handler to every interactive component that is associated with that component.
