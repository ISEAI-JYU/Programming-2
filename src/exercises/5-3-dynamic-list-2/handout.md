Implement a `remove(int index)` method that removes an element from the list at the specified index. The method must return the removed element.

- Elements following the removed element must be shifted to the left so that no "gaps" remain in the array.
- No unnecessary contents may remain in the array after removal.
- Remember to update the size of the list appropriately.

Use the debugger and/or the `get` and `size` methods to verify that the removal was performed correctly.
