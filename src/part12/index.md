# Project Assignment Submission

In week 7 the project is finished and handed off. The week has three steps: the handoff, the final oral, and the reflection.

Before the handoff, make sure that you have addressed all [project requirements](../project-assignment.md) and that the latest version of your project is available in your Git remote repository.

## Handoff

Your pair receives another pair's repository and adds **one small feature** to it. Afterwards, you write about half a page on how easy the code was to work in. The write-up you receive from the other pair is part of the evidence for your project grade: it shows whether another pair could build in your code.

## Final Oral

After the handoff, each student has a **final oral** about the project with the responsible teacher. Be prepared to explain and change any part of your pair's code on your own, and to answer questions about exercise solutions you have submitted earlier in the course.

The project gets one grade, 0–5, from three questions: does it work, could another pair build in it, and can you explain and change it. The third question is judged individually, so partners can end up one grade apart. See [Completing the Course](../completing-the-course.md#project-assignment) for how the project grade counts towards the final grade.

## Reflection

Finally, write a short individual reflection on your work. The reflection is required for completing the course and is assessed on a pass/fail basis; see [Completing the Course](../completing-the-course.md#reflection) for details. Each member of the pair submits their own reflection.
